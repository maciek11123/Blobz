# Blobz

Interactive illustrated characters with physics, sound & gyro gravity.

## Live links
- **[Blobz](https://maciek11123.github.io/Blobz/)** — full version (sounds + gyro)
- **[Blobz Classic](https://maciek11123.github.io/Blobz/classic/)** — original, no gyro, no sounds

Built with vanilla HTML5 Canvas + Web Audio API. No dependencies.

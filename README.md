# Blobz

Interactive illustrated characters with physics, sound & gyro gravity.

## Live
- **[Blobz + Gyro](https://maciek11123.github.io/Blobz/)** — tilt your phone to move them
- **[Blobz Classic](https://maciek11123.github.io/Blobz/classic/)** — audio & responsive, no gyro

Built with vanilla HTML5 Canvas + Web Audio API. No dependencies.
